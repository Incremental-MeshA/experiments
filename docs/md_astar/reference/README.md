# Исходный исследовательский артефакт C++

Эти файлы сохраняют предыдущую работу, из которой перенесена идея MD-A*:

- [Статья PDF](mesh_deferred_cpp_paper.pdf).
- [Полный артефакт](mesh_deferred_cpp_artifact.zip): C++-исходники, доказательства, модели, карты, CSV, проверка архива и контрольные суммы.

Исходная ветка — `research/certified-mesh-a-star`, commit `ec5c97e`. Архив самодостаточен; его внутренний `ARTIFACT_MANIFEST_SHA256.json` описывает каждый файл. Код MeshA* третьей стороны и его MIT-лицензия сохранены внутри архива.

Числа из этой статьи, включая 112×, относятся к другой задаче: C++, исходные control set MeshAStar, целые микростоимости и другой набор нагрузок. **Они не используются как результаты сравнения с Python-алгоритмами данного репозитория.** Новое сравнение выполняется нативно на `car16`, с float-стоимостями и картами `introduction`.
