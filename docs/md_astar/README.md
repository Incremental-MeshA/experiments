## Что перенесено и изменено

MD-A\* поддерживает фактическую и ограниченную рабочую карты. Нижняя оценка для пути через освобождённую клетку компилируется из `build_mesh(car16)`. Очередь откладывает несущественные открытия; при росте верхней границы пересматривает их, включая возвраты старта. При необходимости выполняются один или два вызова MPGAA\*. Используются исходные 284 примитива, 412 конфигураций и float-стоимости; коэффициенты вычисляются заново.

Добавления к прежнему API совместимы:

- `make_planner('md_astar', ...)`, `'mpgaa'`, `'md64'`, `'md_scan'`.
- `planner.replan(start, new_blocks, new_opens=())` принимает освобождения. Старый вызов с двумя аргументами сохраняется.
- D\* Lite получает инвалидирование кеша освобождённых рёбер. На уменьшениях обновляются и ранее неизвестные источники, что необходимо для восстановления связности. Старое правило «только вершины в g/rhs» остаётся для увеличений.
- У `search()` добавлены необязательные `record_expanded=False` и `return_trace=False`: можно вернуть состояния/примитивы без списка раскрытий и полной трассы для визуализации. Значения по умолчанию прежние.

Основной MD-A\* называется `md_astar`; `md64` усиливает оценку 64 коэффициентами, `md_scan` заменяет переносимую очередь полным просмотром отложенных клеток. Это абляции, а не три заявки на новые алгоритмы.

## Запуск

```bash
# Совместимая проверенная среда Python 3.12+; прежний pinned-набор — requirements.txt.
pip install -r requirements-md-astar.txt
python -m mesha.selfcheck
python -m mesha.selfcheck_deferred
python -m mesha.validate_md_suite
python -m mesha.md_benchmark --run --cohort all
python tools_md_analyze.py
python tools_md_report.py --pdf
python tools_md_notebook.py --execute
```

Нагрузки уже зафиксированы. `--prepare` нужен только для повторного построения входов и отказывается перезаписывать существующий файл. Для **новых** измерений сначала сохраните под другим именем `results/md_astar/raw.jsonl`, `environment.json` и `completion_*.json`. Возобновлять частичный прогон следует в той же аппаратной/программной среде; новый прогон нельзя дописывать к временам другой машины.

Все измеряемые эпизоды выполняются последовательно, по три повтора с перемешиванием методов. Сборки, тесты, генерация эталонов и тяжёлый анализ не запускаются параллельно с замерами. Таймер включает применение изменений, поиск и извлечение состояний/примитивов. Визуализация и независимая проверка пути вынесены за таймер. Общая неизменяемая модель готовится заранее; цена компилятора сертификата записана отдельно, а в отчёте есть консервативная метрика с добавлением этой цены один раз на эпизод.

Для полной задержки используется внешний таймер, а не внутренние поля `elapsed_s`: в исходных API момент построения возвращаемого пути и служебного индекса относительно внутреннего таймера различается. Такие поля не подставляются в новые временные отношения.

Лимит D\* Lite в новых длинных эпизодах задаётся на каждый запрос. Первый проход с накопительным ограничителем сохранён в `results/md_astar/development/cumulative-budget-v1`: в итоговых данных остались только полностью завершённые парные эпизоды, в которых старый предел ни разу не сработал. Неполный эпизод повторяется целиком. `tools_md_budget_migrate.py` проверяет одинаковую среду, точный diff единственного присваивания и неизменность кода алгоритмов. Фаза записана для каждого эпизода в итоговом CSV; разные фазы не смешиваются внутри парного сравнения.

Исходные времена из `results/runs.json` не используются для ускорений. Сверка всех 561 исходных запросов использует только их контрольные стоимости. Для времени выбраны 24 эпизода по квантилям длины пары на каждой карте, до просмотра времён MD-A\*. Дополнительно подготовлены смешанные изменения, новый seed и диагностические пустые карты. Mesh/ParallA\* остаётся приближённым контролем; его скорость рассматривается вместе с качеством пути.

## Пример API

```python
import numpy as np
from mesha.primitives import build_control_set
from mesha.mesh import build_mesh
from mesha.incremental import make_planner

control = build_control_set('car16')
mesh = build_mesh(control)
grid = np.zeros((36, 48), dtype=np.uint8)
planner = make_planner('md_astar', grid, control, mesh, (18, 4, 0), (18, 40, 0))
first = planner.plan()
repaired = planner.replan((18, 4, 0), new_blocks=[(18, 22)])
reopened = planner.replan((18, 4, 0), new_blocks=[], new_opens=[(18, 22)])
print(reopened.cost, reopened.backend_calls, reopened.certified)
```

## Что проверено

`selfcheck_deferred` использует отдельный Dijkstra без эвристики, кешей и классов графа планировщиков; проверяет каждую покрытую клетку возвращённого пути. Есть случаи разреза карты и открытия ранее не посещённых компонент, одновременных изменений, возврата старта, повторных одинаковых правок, блокировки концов для MD-A\*/MPGAA\*, очистки устаревшей кучи и реактивации старого освобождения после поломки пути.

D\* Lite сохраняет предположение исходного проекта, что начальная и конечная клетки свободны. Численная проверка стоимостей использует допуск `1e-6`. Лимит раскрытий выдаёт `capped`, а не корректный ответ об отсутствии пути; измерительный скрипт останавливается при таком результате. Математическая точность MD-A\* доказана для идеальной арифметики, а float-реализация проверена на указанных нагрузках.

Подробная оценка достоинств и недостатков находится в [новом отчёте](report.md). Из исходного бенчмарка с гарантированными поломками маршрута нельзя вывести преимущество отсрочки освобождений: в нём освобождений нет. Эффект нового механизма нужно оценивать отдельно от эффекта самого MPGAA\* и от различий языка реализации.
