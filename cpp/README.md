# C++17-реализации для измерений

Это самостоятельный порт **той же модели**, что использована в Python-эксперименте ветки `research/md-astar`: исходные `car16`, 284 примитива, 412 mesh-конфигураций, float-стоимости кривых и полные supercover-трассы. Старый C++-артефакт с другими примитивами/целыми стоимостями не используется.

Поиск, ремонт, извлечение состояний/примитивов, MD-очередь и таймер написаны на C++. Python нужен для повторного экспорта данных и удобного сохранения метаданных/анализа CSV; готовые `.txt` позволяют запускать бинарник без Python и NumPy. Сторонних C++-библиотек и загрузок при сборке нет.

Выполненный прогон: **1200 запусков / 8400 проверенных вызовов**, плюс отдельная сверка 5610 вызовов на всём исходном корпусе. Независимый Дейкстра проверил 2940 ответов; тот же набор прошёл ASAN/UBSAN. [Новые C++-таблицы](results/raw.summary.md), [проверки](results/verification/README.md). Медианные онлайн-ускорения MD-A\* относительно общего MPGAA\*: 1,058× на исходных, 1,020× на смешанных, 0,989× на новом seed, 169,891× на целевой диагностике. Это описательные результаты проверенного порта; на исходном наборе LBA\* быстрее MD-A\*, а универсальное преимущество нового механизма из этих чисел не следует.

## Сборка и быстрый запуск

Из корня репозитория, GCC/Clang с C++17 и GNU Make:

```bash
make -C cpp -j2
make -C cpp test
mkdir -p cpp/results
cpp/build/mesh_bench --input cpp/data/car16_md.txt \
  --output cpp/results/my_run.csv --repeats 3
```

В проверенной сборке используются `-O3 -DNDEBUG -std=c++17`, без `-ffast-math`. Бинарники не входят в git. Чтобы изменить флаги, используйте чистую сборку или отдельный каталог:

```bash
make -C cpp BUILD=build-custom CXX=clang++ \
  CXXFLAGS='-O3 -DNDEBUG -std=c++17 -Wall -Wextra -Wpedantic'
```

Также предоставлен `CMakeLists.txt`: `cmake -S cpp -B cpp/build-cmake -DCMAKE_BUILD_TYPE=Release`, затем `cmake --build cpp/build-cmake`. Основной проверенный путь — Make; в текущей среде CMake не установлен.

## Что реализовано

| Ключ | Реализация |
| --- | --- |
| `lba` | A\* по полным примитивам, проверка трассы перед добавлением преемника. |
| `lazy_lba` | Ленивая проверка трассы при извлечении из OPEN. |
| `mesha` | Поиск по внутренним mesh-конфигурациям, нулевые внутренние рёбра и полная цена на завершении; отсечение по концам пучка. |
| `mesh_parall` | Мягкие дубликаты по двухшаговым сигнатурам; 100 шагов mesh на один шаг LBA\*. Полный приближённый контроль, может вернуть неоптимальный путь. |
| `dstar_lattice` | D\* Lite по решётке примитивов, с кешем рёбер и обратными зависимостями. |
| `dstar_mesh` | То же ядро D\* Lite по внутреннему mesh; обрабатывает равные ключи и нулевые рёбра. |
| `mpgaa` | MPGAA\* на ориентированном графе: адаптивная эвристика, её ремонт при освобождениях, переиспользование путей и консервативная пространственная рамка уведомлений. |
| `md_astar` | MD-A\*: тот же класс MPGAA\*, рабочая карта, скалярный mesh-сертификат, переносимая очередь и индекс допустимости суффикса. |
| `md64` | Абляция: 64 направленных коэффициента вместо скалярной оценки. |
| `md_scan` | Абляция: полный просмотр отложенных клеток вместо переносимой кучи. |

Ни один метод не является вызовом Python или переименованием другого поиска. Общие структуры находятся в `include/ima/model.hpp`; реализации разделены на `search.hpp`, `dstar.hpp`, `adaptive.hpp`, `deferred.hpp`. Публичная фабрика — `include/ima/planners.hpp`.

## Замеры с происхождением данных

```bash
python cpp/run.py --output cpp/results/new_run.csv --repeats 3
python cpp/analyze.py cpp/results/new_run.csv
```

`run.py` сначала собирает release-бинарник **вне замера**, проверяет манифест экспорта, сохраняет CPU, платформу, SHA-256 бинарника/исходников/входов и запускает один последовательный C++-процесс. Примеры ограничения набора:

```bash
python cpp/run.py --methods lba,dstar_mesh,mpgaa,md_astar \
  --cohort mixed --output cpp/results/mixed_new.csv
python cpp/run.py --case diagnostic__160 \
  --output cpp/results/diagnostic_new.csv --repeats 5
```

По умолчанию измеряются все десять методов на всех 40 эпизодах, включая абляции в каждом наборе: **1200 запусков / 8400 вызовов** при трёх повторах. Это отличается от плана Python, где абляции измерялись только на двух наборах. Методы перемешиваются на каждом повторе эпизода; mutable-поисковое состояние между эпизодами/повторами не переносится.

CSV содержит время каждого запроса, отдельный конструктор, стоимость, число примитивов, hash пути, раскрытия, чтения клеток, группы уведомлений, извлечения очереди ремонта эвристики и показатели MD. Счётчики и hash пути обязаны совпадать между повторами одного метода. Между языками одинаковый путь или число раскрытий не требуются: порядок равных стоимостей/уведомлений может отличаться.

Таймер `steady_clock` включает применение правок, поиск/ремонт, извлечение пути и обновление индекса сохранённого пути. Проверка каждой покрытой клетки, курса и стоимости выполняется **после остановки таймера**, по отдельной фактической карте, без обращения к кешам планировщика. Подготовка неизменяемой модели и компилятор сертификата измерены отдельно в JSON. Общее значение времени эпизода включает конструктор и первый запрос; онлайн-метрика исключает первый запрос.

Точные методы сравниваются с зафиксированными стоимостями LBA\* с допуском `1e-6`; Mesh/ParallA\* оценивается по достижимости и отношению стоимости к оптимуму. Превышение бюджета **останавливает прогон**, а не становится ответом о недостижимости. Предел применяется на каждый запрос; у MD он общий на оба возможных вызова ядра. Воспроизводимый запуск отказывается перезаписывать существующие результаты; для нового прогона укажите новый файл. Completion JSON создаётся только после полного успеха, а прерванный CSV остаётся частичным.

Не запускайте сборки, другие тесты и замеры параллельно с измерением. Санитайзерные и отладочные времена не используются для сравнения. Сравнивать скорость разных алгоритмов следует внутри одной новой C++-серии; прежние Python-секунды и старые C++-времена сюда не подмешиваются. Новое C++-сравнение и его ограничения находятся в [`results/raw.summary.md`](results/raw.summary.md), если выполнен стандартный сохранённый прогон.

## Данные и полный исходный корпус

Готовые файлы находятся в `data/`, рядом — манифесты SHA-256. Экспорт 17 значащими десятичными цифрами сохраняет исходные binary64, стоимость не квантуется. Mesh, сигнатуры и трассы экспортируются из неизменённого Python-конструктора; **сертификат вычисляется в C++**, а не загружается как готовая Python-оценка.

```bash
python cpp/export_inputs.py --output cpp/data/car16_md.txt
python cpp/export_inputs.py --suite upstream --output cpp/data/car16_upstream.txt
python cpp/export_inputs.py --suite model --control legacy8 --output cpp/data/legacy8.txt
python cpp/run.py --input cpp/data/car16_upstream.txt --verify-only \
  --output cpp/results/upstream_check.csv
```

`--verify-only` выполняет один повтор и проверяет все ответы, но анализатор не принимает этот файл как измерение скорости. Полный исходный корпус — 187 эпизодов / 561 запрос; дополнительный набор — 40 / 280. Существующие Python-результаты и статья сохранены отдельно.

## Независимые проверки и санитайзеры

```bash
make -C cpp test
make -C cpp sanitize
ASAN_OPTIONS=detect_leaks=1 UBSAN_OPTIONS=halt_on_error=1 \
  cpp/build-sanitize/mesh_tests cpp/data/car16_md.txt cpp/data/legacy8.txt
```

Дейкстра в `tests/selfcheck.cpp` напрямую читает примитивы и карту, не использует классы графов, кеши или эвристики планировщиков. Проверяются все курсы, car16 и legacy8, разрез/открытие компонент, смешанные и повторные правки, возвраты старта, блокировка концов для новых планировщиков, 160 событий ленивого удаления. Контрпример `13 → 13 → 19` требует повторно активировать старое открытие и выполнить два вызова MPGAA\*. 64 коэффициента сверяются с плоским перебором и проверяются на 128 геометрических тройках для каждой модели. Тесты используют явные проверки, работающие и с `NDEBUG`.

## API

```cpp
#include "ima/planners.hpp"

auto suite = ima::read_suite("cpp/data/car16_md.txt");
ima::Certificate certificate(suite.model);
auto const& episode = suite.episodes.front();
auto const& query = episode.queries.front();
auto planner = ima::make_planner("md_astar", suite.maps[episode.map],
    suite.model, certificate, query.start, query.goal);
ima::Path path = planner->replan(query.start, query.blocks, query.opens);
```

Цель, модель и сертификат должны жить дольше планировщика. Каждый планировщик владеет изменяемой картой; интерфейс — `replan(start, blocks, opens)`. Цель фиксирована. D\* Lite явно требует свободных концов. `mesh_parall` приближённый. Float-реализация проверяется с допуском, математическая теорема MD относится к идеальной арифметике. Заголовки используют sparse hash-таблицы и обычные очереди STL; это проверенный порт для контролируемых измерений, без заявления об оптимальности реализации по памяти или времени.
