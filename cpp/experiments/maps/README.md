# Карты

Официальные архивы Moving AI Lab загружены по URL из `SOURCES.json`; там сохранены SHA-256 архивов и карт. Поддержка набора: Nathan Sturtevant / Moving AI Lab. DAO arena предоставлена BioWare; случайные, комнатные и лабиринтные карты — Nathan Sturtevant / HOG2. Данные распространяются по [Open Data Commons Attribution License](https://opendatacommons.org/licenses/by/1-0/).

Цитирование: N. Sturtevant, *Benchmarks for Grid-Based Pathfinding*, IEEE TCIAIG 4(2), 144–148, 2012. [Страница коллекции](https://www.movingai.com/benchmarks/grids.html).

Файлы 512×512 сохранены целиком. В основных новых car16-экспериментах используются явно обозначенные окна `(0,0,96,96)` Room/Random/Maze; arena используется целиком. Berlin и AR0700SR берутся без изменений из исходного `data/maps` репозитория. Bernoulli-карты 50×50 генерируются отдельными фиксированными seed, что указано в контекстах. Карты из официальных коллекций и синтетические карты не смешиваются под одним происхождением.
