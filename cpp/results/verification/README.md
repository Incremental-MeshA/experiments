# Проверки нативного C++-порта

- `oracle.log`: release-сборка прошла 296 независимых снимков Дейкстры и 2940 сравнений. Проверка приближённого Mesh/ParallA\* требует правильной достижимости, допустимости пути и стоимости не ниже оптимума; для остальных методов требуется совпадение с оптимумом.
- `sanitizers.log`: тот же набор прошёл с AddressSanitizer, проверкой утечек и UndefinedBehaviorSanitizer (`halt_on_error=1`).
- `upstream.csv`: все 187 исходных эпизодов / 561 запрос выполнены каждым из десяти C++-методов: 1870 запусков / 5610 вызовов. Для каждого ответа проверены стоимость, конечный курс и все покрытые клетки; превышений лимита не было.
- `upstream.csv.json`: завершение полного корпуса, точные флаги и параметры, включая `verify_only=true`.
- `upstream.csv.provenance.json`: SHA-256 исходников, бинарника и входов, среда и хеши завершённых результатов.

**Времена `upstream.csv` не используются в сравнении скорости:** это однократная функциональная сверка. Три последовательных повторения отдельного временного набора находятся в `../raw.csv`, их анализ — в `../raw.summary.md`. Первоначальная статья и Python-результаты лежат отдельно в `docs/md_astar` и `results/md_astar`.

Тесты содержат car16, legacy8 и независимую игрушечную модель, все стартовые курсы, разрезы и повторное соединение компонент, смешанные и повторные правки, возвраты старта, блокировку концов для новых планировщиков, 160 событий очистки ленивой кучи и контрпример повторной активации старого освобождения с двумя вызовами ядра. Все 64 mesh-коэффициента сверены с плоским перебором; по 128 геометрических троек проверены на каждой из трёх моделей. Явные проверки работают и при `NDEBUG`.
