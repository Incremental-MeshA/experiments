# Определения прежнего прототипа

Эти файлы сохранены побайтно для проверки происхождения C-Mesh, Suffix-Mesh и Boundary-Mesh. Хеши и исходные пути приведены в [origin.json](origin.json); прежнее описание — в [prototype_README.md](prototype_README.md). Они используют целочисленные микростоимости. Их бинарники и времена в новую серию не входят.

Текущая реализация с исходными float-стоимостями находится в [variants.hpp](../variants.hpp), команды запуска и протокол — в [README дополнения](../README.md). Для воспроизведения используйте их.
