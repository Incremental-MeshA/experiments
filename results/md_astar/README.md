# Нативные измерения MD-A\*

Этот каталог содержит новые последовательные Python-измерения для ветки `research/md-astar`. Исторические времена из `../runs.json` и справочного C++-архива в ускорения не входят. Контрольные стоимости исходного LBA\* используются для проверки ответов.

| Файл | Содержание |
| --- | --- |
| `raw.jsonl` | Одна строка на полный запуск одного метода на одном эпизоде. Ключ: `(id, method, repeat)`. Внутри `rows` находятся запросы эпизода. |
| `environment.json` | Среда, SHA-256 измеряемых исходников и входов, отдельная цена компилятора сертификата, описание сохранённой предыдущей фазы. |
| `completion_all.json` | Признак завершения runner. Наличие частичного `raw.jsonl` не означает завершённого сравнения. |
| `analysis.json` | Проверенная полнота данных, парные ускорения и агрегаты по наборам. |
| `sequence_metrics.csv` | Медианы сумм времени по трём повторам каждого метода/эпизода; в `measurement_phase` указана фаза протокола. |
| `summary.csv` | Компактные агрегаты для графиков и отчёта. |
| `verification.json` | Независимый Dijkstra, проверка путей, алгебры сертификата и динамических регрессий. |
| `full_verification.json` | Оба новых планировщика на всех 561 запросах исходного корпуса. |
| `upstream_selfcheck.log` | Успешная исходная проверка проекта. |
| `development/cumulative-budget-v1/` | Полный архив первого прохода, включая незавершённый эпизод, журнал срабатывания накопительного лимита и снимок всех исходников. |

Нагрузки находятся в [`data/benchmarks/md_astar.json`](../../data/benchmarks/md_astar.json): 40 эпизодов и 280 записей «эпизод, запрос». Повторы и методы не считаются новыми задачами. Основных методов восемь; на смешанном и диагностическом наборах дополнительно измерены две абляции. Полный план содержит 1032 запуска и 7656 вызовов.

## Поля запроса в `raw.jsonl`

| Поле | Значение |
| --- | --- |
| `query` | Номер запроса, начиная с нуля; нулевой — первичное планирование. |
| `cost` | Сумма исходных float-стоимостей примитивов; `null` означает доказанную недостижимость. Превышение лимита не сохраняется как недостижимость: runner останавливается. |
| `time_s` | Внешний таймер: правки карты, планирование и извлечение состояний/примитивов. Проверка пути выполняется за таймером. |
| `setup_s` | Конструктор планировщика; записан один раз при `query=0`. Общая неизменяемая модель готовится заранее. |
| `expansions` | Счётчик данной реализации. Для MPGAA\*/MD-A\* это прямой A\*, без извлечений очереди ремонта эвристики; для D\* Lite — его очередь ремонта. Разные представления состояний также дают разные единицы. |
| `checked_cells` | Новые чтения клеток при проверке рёбер, включая извлечение пути D\* Lite. Кешированные проверки могут не читать карту. |
| `notify_probes` | Проверенные группы обратных зависимостей в MPGAA\*/MD-A\*; ноль у остальных методов не означает отсутствие их расходов на обновления. |
| `certified` | MD вернул ответ без вызова ядра. Включает сертификат повторной недостижимости; это не флаг у других алгоритмов. |
| `backend_calls` | Число вызовов MPGAA\* для MD: 0, 1 или 2. Значение по умолчанию у остальных методов служебное. |
| `activated_cells`, `deferred_cells`, `refined_cells` | Число включённых в рабочую карту, оставшихся отложенными и уточнённых клеток MD. |
| `category`, `event` | Зафиксированные свойства контрольной задачи и события; не выбираются по результату кандидата. |
| `suboptimality` | Отношение возвращённой стоимости к точному контролю. Mesh/ParallA\* допускает превышение единицы. |

Онлайн-время — сумма `time_s` при `query>0`. Время эпизода — все запросы плюс конструктор. Метрика `cold_certificate_s` дополнительно начисляет MD цену компилятора один раз на эпизод. Ускорение — время контроля, делённое на время MD; сначала берётся медиана трёх повторных сумм, затем медиана парных отношений по эпизодам. Интервалы на четырёх картах описательные, с кластерной перевыборкой карт; они не подтверждают перенос на генеральную совокупность карт.

## Две фазы одного протокола

Первый проход применил прежний предел D\* Lite в 3 млн раскрытий накопительно к длинному эпизоду. После обнаружения ошибки ограничитель выдаёт 3 млн на каждый запрос. Это единственное изменение измеряемого runner; присваивание выполняется вне таймера. Код алгоритмов и входы не менялись.

Сохранены только 21 целиком завершённый парный эпизод (534 запуска), в которых прежний ограничитель ни разу не сработал. Три завершённых запуска незаконченного эпизода остались только в архиве; сам эпизод повторён целиком. Разные фазы внутри одной пары не смешиваются. [`tools_md_budget_migrate.py`](../../tools_md_budget_migrate.py) проверил точный diff и среду; анализ проверяет архивные исходники, хеши и полноту ключей.
